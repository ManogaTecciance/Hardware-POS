AxloPOS Printer Setup

For the counter PC · Windows 10/11

How to make AxloPOS print kitchen tickets and bills at your restaurant. One small program (the print agent) runs on the counter PC and reaches your printers; everything else is done in the app.

0Before you start

  • The counter PC (Windows 10 or 11) is on the restaurant Wi-Fi or LAN and stays switched on during service.
  • You have the agent zip (axlo-print-agent-0.3.0.zip) — from AxloPOS support.
  • You can log in to AxloPOS as the owner.
  • Printers are unboxed, with 80 mm receipt rolls (not sticker labels) loaded.
  • The kitchen printer's LAN cable goes into the router or switch — never into a PC.

1Install the print agent (5 minutes)

  1. Unzip the agent zip anywhere — the Desktop is fine.
  2. In AxloPOS: Settings → Printing → Print agent → Pair a new agent. Name it (for example Counter PC) and press Pair agent.
  3. The box that appears shows two things: the API address and the token (starts with pat_). The token is shown once — keep the box open.
  4. Double-click install.cmd in the unzipped folder. Say Yes when Windows asks for permission.
  5. It asks for the API address — paste the one from the box (press Enter if the default it shows already matches). Then paste the token.
  6. Wait for Service installed and running and The agent reached … and scanned for printers, then press Enter to close.
Back in AxloPOS, the agent shows Online within a few seconds — no reload needed. The installer set everything else up: Node.js if it was missing, a Windows service that starts before anyone logs in and restarts itself, and "never sleep" on mains power.
If the window ends with FAILED: …, the reason is written just above it — most often the API address was typed wrong. Run install.cmd again and paste the address exactly as the app shows it. Still stuck? Take a photo of the window and send it to AxloPOS support.

2Connect the printers

The app addresses each printer by how the counter PC reaches it. Pick the kind that matches, then follow its three steps.

Network

Kitchen receipt printer with an IP address

Cable to the router, or a Wi-Fi receipt printer. Tested with Xprinter XP-Q80B.

  1. Plug the LAN cable into the router, power on.
  2. Hold FEED while switching it on: the self-test page prints its IP (Xprinter default 192.168.123.100).
  3. Keep that page — the app finds the printer by itself, and the IP on the page is what support will ask for. Nothing to install on the PC.
USB

Bill printer plugged into the PC

Tested with Xprinter XP-365B (dual-mode — see the note).

  1. Install the printer's Windows driver on the counter PC so it appears in Printers & scanners.
  2. Print a Windows test page — if that works, AxloPOS can print too.
  3. Xprinter XP-365B only: power off → rear DIP switch 1 → OFF (receipt mode) → power on.
Wi-Fi / office

Office inkjet or laser on the Wi-Fi

Prints the ticket as a plain-text page on normal paper. Tested with Canon G3010.

  1. Connect the printer to the restaurant Wi-Fi.
  2. Add it on the counter PC: Settings → Printers & scanners → Add device.
  3. Print a Windows test page.
The XP-365B label-mode trap. In label (TSPL) mode the Windows test page prints but every AxloPOS bill is silently ignored. Set DIP switch 1 to OFF, switch the printer off and on, and load a continuous receipt roll.

4Prove it with one order

  1. Place a dine-in order and send it — a kitchen ticket prints within about 3 seconds.
  2. Settle the order — the bill prints on the counter printer.
  3. Settings → Printing → Print queue shows 0 pending, 0 failed.

5Every day after that

  • Switching the PC on is enough. The agent starts with Windows, before anyone logs in, and shows Online within seconds. Nobody starts anything by hand.
  • A new printer: install its driver (USB / Wi-Fi office) or plug it into the router (network), then Add printer in the app. The agent finds it by itself.
  • Updates happen by themselves: when AxloPOS is updated, the agent fetches its new version, checks it, and restarts in a few seconds. No action at the restaurant.
  • Internet drops: orders keep going to the kitchen screen; tickets print as soon as the connection returns. Nothing is lost.
  • Power cut mid-print: that ticket prints again when power returns — twice is possible, never zero.

For your technician (you do not need this)

The agent lives in C:\axlo-print-agent and runs as the Windows service AxloPrintAgent. Its log is agent.log in that folder; the installer's log is %TEMP%\axlo-print-agent-install.log. install.cmd -Uninstall removes the service. Xprinter drivers and tools: xprintertech.com/download.html. Moving to a new PC: install there with a new pairing token, then press Remove on the old agent in the app.
